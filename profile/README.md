## Inside EPA SWMM

EPA SWMM is a local Windows stormwater app with a named swmm desk, a short node list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside a catchment you already keep and holds only the node that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra nodes wait for their own title. EPA SWMM starts with a local profile and does not need a complex account system.

The swmm desk stays on a model you already own. Untitled nodes stay off the live list.
